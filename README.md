# 太阳系 · Solar System (Three.js)

基于 **Three.js + Vite** 的太阳系演示：八大行星使用 2K 贴图建模，月球潮汐锁定绕地球公转，土星环沿半径展开，支持**全局漫游 ⇄ 自由遨游**双视角模式。

## ✨ 特性

**场景**

- 🌞 太阳：自发光球体 + 加色混合光晕（canvas 径向渐变生成，无外部资源依赖）
- 🪐 八大行星：球体 + 2K 贴图，含真实自转轴倾角（天王星 97.8° 侧躺）与轨道倾角，金星逆行自转
- 🌙 月球：绕地球公转，潮汐锁定（始终同一面朝向地球）
- 💫 土星环：alpha 贴图圆环，RingGeometry UV 沿半径重映射，环缝渐变正确展开
- ⭕ 轨道线：八大行星 + 月球轨道，含真实轨道倾角
- 🌌 背景：银河天球（内表面渲染）

**交互**

- 双视角模式：全局漫游（OrbitControls）⇄ 自由遨游（自写 FreeFlight：WASD 平移、拖拽转向、滚轮调速、Shift 加速），`V` / `Esc` / 右上角按钮切换
- 飞行手感：指数阻尼平滑加减速（帧率无关）、俯仰限位防翻转、银河天球软边界防"飞出宇宙"
- 防卡键：窗口失焦自动清空按键状态

**健壮性**

- WebGL 不可用时显示友好错误提示，不白屏
- 单张贴图加载失败 → 对应天体降级为兜底纯色球（土星环失败则隐藏），场景整体不受影响
- 加载进度实时显示 + 15s 超时兜底撤掉遮罩
- 帧间隔 clamp（切标签页回来天体不瞬移）、devicePixelRatio 上限 2、resize 时同步 DPR 变化

## 🚀 快速开始

环境要求：Node.js `^20.19.0 || >=22.12.0`

```bash
npm install    # 安装依赖
npm run dev    # 开发服务器，浏览器自动打开 http://127.0.0.1:5173
```

构建与预览：

```bash
npm run build     # 产物输出到 dist/（自包含：HTML + JS + 全部贴图）
npm run preview   # 本地预览构建产物
```

`dist/` 可直接部署到任意静态托管（GitHub Pages、Vercel、Nginx 等）。

## 🎮 操作

**全局漫游**（从遨游模式按 `V` / `Esc` 或点右上角按钮进入）

| 操作 | 效果 |
| --- | --- |
| 左键拖拽 | 旋转视角 |
| 滚轮 | 缩放 |
| 右键拖拽 | 平移视角 |

**自由遨游**（默认模式；右上角按钮或 `V` 键切换）

| 操作 | 效果 |
| --- | --- |
| W / S / A / D（或方向键） | 前后左右平移 |
| R / F | 上升 / 下降 |
| 左键拖拽 | 转向（俯仰限位防翻转） |
| 滚轮 | 调节飞行速度（2–300，HUD 实时显示） |
| Shift | 3 倍加速 |
| V / Esc | 返回全局视图 |

飞行带速度阻尼（平滑加减速），切窗自动清空按键防"卡键"。

## 🪐 实现要点

- **场景层级**：`orbitGroup`(轨道倾角) → `pivot`(公转) → `system`(轨道锚点) → `tiltGroup`(自转轴倾角) → `mesh`(自转)，卫星挂在锚点下随行
- **潮汐锁定**：月球不设本地自转，跟随公转枢轴旋转即每轨道恰好自转一周，恒以同一面朝向地球
- **土星环 UV 重映射**：RingGeometry 默认 UV 为平面投影，无法让环贴图沿半径铺开；将 u 重映射为归一化半径、v 固定 0.5，匹配横向条带状 alpha 贴图
- **自写 FreeFlight 而非内置 FlyControls**：内置版键盘监听挂在 canvas 上，canvas 无焦点时 WASD 静默失效；自写约 70 行（欧拉 YXZ 顺序 + 俯仰限位 + 指数阻尼）行为完全可控
- **双控制器互斥**：OrbitControls 通过 `enabled` 开关隔离输入，动画循环按模式只 update 活跃控制器，切换时相机位置保持连续
- **中文贴图文件名**：`encodeURI` 运行时编码 URL；`vite.config.js` 将 `publicDir` 指向 `textures/`，dev 与 build 均无需移动原始素材
- **vite.config.js 不含 import**：避免 Vite 加载 config 时解析外部依赖路径，在无法 spawn 子进程的受限环境（沙箱/CI）中也能正常构建

## 🔧 参数调整

全部参数集中在 [`src/main.js`](src/main.js) 顶部：

- `CONFIG`：太阳半径、公转/自转基准速度、相机参数、加载超时等
- `PLANETS`：每颗行星的半径、轨道距离、公转/自转周期、轴倾角、轨道倾角、兜底颜色
- `MOON`：月球半径、地月距离、公转周期

## 📏 比例说明（艺术化压缩）

真实比例下行星小到肉眼不可见，因此做了压缩，各天体保持相对关系：

- **尺寸/距离**：行星观感放大约 2 倍、轨道距离手工压缩的观感值
- **公转周期**：以地球 20 秒/圈为基准，按 `pow(周期年, 0.6)` 压缩换算
- **自转周期**：以地球 8 秒/圈为基准，按 `sqrt(|周期天|)` 换算（负值 = 逆行）

## 📁 目录结构

```
├── index.html          # 入口页面（HUD / 模式按钮 / 加载遮罩）
├── vite.config.js      # publicDir 指向 textures（贴图无需移动即可访问）
├── src/
│   ├── main.js         # 场景逻辑（全部代码）
│   └── style.css       # HUD / 加载遮罩 / 错误提示样式
└── textures/           # 2K 行星贴图（原始素材，未随代码改动；同名替换即可换肤）
```

## 🖼️ 贴图说明

`textures/` 目录为独立的 2K 行星贴图素材（未包含在本仓库的代码改动范围内），文件名与 `main.js` 中的 `TEX` 清单一一对应。如需替换贴图，保持文件名同名覆盖即可。
